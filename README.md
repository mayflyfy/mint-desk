## 常用功能

| 整理 | 操作 |
| --- | --- |
| 列表 / 网格 | 拖入文件、文件夹、快捷方式，双击打开 |
| 拖动排序 | 卡片内排序、跨卡片移动；Ctrl 拖动复制入口 |
| 自由布局 | 缩放、锁定、收起；边缘吸附和临时对齐线，可自由拖离 |
| 薄荷绿外观 | 半透明背景，可用时启用系统毛玻璃 |
| 多屏使用 | 按显示器 DPI 缩放，自动保存布局 |
| 启动与退出 | 自动启动；托盘可关闭自启动、右键入口或退出 |

## 三步开始

1. 下载 `setup-x64.exe`，选择安装目录、桌面快捷方式和开机启动。
2. 把桌面项目拖入卡片，按喜好排列。
3. 启用开机启动后，登录 Windows 自动恢复上次布局。

也可选择便携 ZIP，解压到固定位置运行。安装版更新运行新安装包，继续使用原安装目录；旧版便携用户可直接使用安装包，沿用原有布局和文件记录。安装完成后可删除下载的安装包，安装目录里的 `MintDesk.exe` 需要保留。[安装、更新与移动说明](docs/usage.md#安装程序)

桌面原文件保持原路径，收进卡片后临时隐藏，正常退出恢复；隐藏同时影响资源管理器。详见[使用与恢复说明](docs/usage.md)。
