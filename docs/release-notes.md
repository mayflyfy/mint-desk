# 薄荷桌面助手 / MintDesk v0.8.0

首个公开版本的本地发布准备。

- 极简、开源、薄荷绿视觉风格，原生 C++17 / Win32，单个 Windows x64 便携 EXE。
- 列表 / 网格、卡片内排序、跨卡片拖动、边缘吸附、锁定和收起。
- 桌面项留在原路径，临时隐藏；正常退出恢复，带双份恢复记录及独立恢复守护。
- 首次正常启动自动配置开机启动和桌面右键；后续手动关闭会被保留。
- MIT License，Copyright (c) 2026 MCC。

下载 Windows x64 ZIP，解压到固定位置后运行 `MintDesk.exe`。也可下载独立 EXE；`SHA256SUMS.txt` 提供校验。

隐藏属性同时影响资源管理器显示。重要资料仍应有独立备份。程序未签名，系统可能显示安全提示。完整使用说明及验证边界见仓库文档。

本页及发布包仅在本地准备，等待维护者确认发布。
