# 薄荷桌面助手 / MintDesk v0.8.0

首个公开版本：极简、开源、薄荷绿，专注桌面整理。

| 特点 | 说明 |
| --- | --- |
| 轻巧 | EXE 约 0.42 MB，ZIP 约 0.20 MB |
| 打开即用 | 单文件便携程序，无需额外依赖或运行库 |
| 低占用 | 本机短时实测主进程工作集约 31 MiB，私有内存约 9 MiB；辅助进程另计 |
| 安静 | 无广告、推广、通知弹窗，无联网服务与遥测 |
| 卡片整理 | 列表 / 网格、拖动排序、跨卡片移动 |
| 布局 | 缩放、锁定、收起、边缘吸附、多屏布局保存 |
| 自动启动 | 首次打开自动配置开机启动和桌面右键，可在托盘关闭 |
| 协议 | MIT · © 2026 MCC |

**下载：** Windows 10 / 11 x64 用户下载 ZIP，解压到固定位置后运行 `MintDesk.exe`；也提供独立 EXE 和 `SHA256SUMS.txt`。

桌面项保留原路径，仅临时隐藏，正常退出恢复。Windows 可能对未签名程序显示安全提示，受保护项目可能需要管理员确认。资源占用随环境变化，详见仓库[使用说明](https://github.com/mayflyfy/mint-desk/blob/main/docs/usage.md)与[验证范围](https://github.com/mayflyfy/mint-desk/blob/main/docs/verification.md)。
