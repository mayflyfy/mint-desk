# 薄荷桌面助手 / MintDesk v0.8.1

| 更新 | 效果 |
| --- | --- |
| 取消选中 | 点击其他卡片或桌面，即取消原条目的选中效果 |
| 自由拖动 | 修复吸附后拖不走；慢慢拖动也能脱离，吸附时显示临时对齐线 |
