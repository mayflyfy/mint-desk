# 薄荷桌面助手 / MintDesk v0.9.1

- 提供完整安装包，支持全新安装与原目录升级，包含全部功能；继续提供独立 EXE 和便携 ZIP。
- 修复跨卡片拖动时图标不跟随鼠标的问题，兼容旧式图标与尚未加载的图标。
- 软件卸载、文件或快捷方式被删除后，自动移除卡片内的失效入口并保存布局。
- 根据本地文件变化触发后台检查；保留暂时不可用的网络和移动硬盘入口，拖放或菜单操作结束后再清理。
- 通过全部 12 组原生测试，包括真实 Windows 拖动图标初始化、原生文件删除通知和布局保存。
- 更新紧凑多卡片展示图，使用真实 Windows 文档、应用与文件夹图标，并展示拖动图标、插入线和目标卡片提示。

## v0.9.0 安装功能

- 新增 EXE 安装程序，可选择目录、桌面快捷方式和开机启动，无需管理员权限。
- 自动检查更新默认不勾选；当前仅保存设置，暂不联网、不下载、不提示。
- 兼容 v0.8.x 便携用户，沿用原有布局、顺序和恢复记录，保留关闭的集成选项。
- 升级、卸载先正常退出并完成桌面恢复，失败时停止，不强制结束进程。
- 卸载保留用户数据；继续提供便携 ZIP 和独立 EXE。

安装版更新请运行新安装包并继续使用原安装目录。安装完成后可以删除下载的 setup 文件，安装目录中的 MintDesk.exe 需要保留。
