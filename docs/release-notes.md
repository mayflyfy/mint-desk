# 薄荷桌面助手 / MintDesk v0.9.0

- 新增 EXE 安装程序，可选择目录、桌面快捷方式和开机启动，无需管理员权限。
- 自动检查更新默认不勾选；当前仅保存设置，暂不联网、不下载、不提示。
- 兼容 v0.8.x 便携用户，沿用原有布局、顺序和恢复记录，保留关闭的集成选项。
- 升级、卸载先正常退出并完成桌面恢复，失败时停止，不强制结束进程。
- 卸载保留用户数据；继续提供便携 ZIP 和独立 EXE。

安装版更新请运行新安装包并继续使用原安装目录。安装完成后可以删除下载的 setup 文件，安装目录中的 MintDesk.exe 需要保留。
