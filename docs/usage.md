# 使用与恢复

## 卡片操作

- 拖动标题栏移动，拖动边缘调整大小；靠近边缘时吸附并显示临时对齐线，继续拖远即可脱离。Alt 临时关闭吸附，键盘移动不吸附。
- 右上角依次为收起 / 展开、锁定、菜单。锁定限制卡片移动和缩放。
- 双击标题或 F2 改名；双击条目或 Enter 打开，Delete 移除卡片入口。
- 点击另一张卡片或桌面会取消原卡片中的条目选中。
- 在列表 / 网格中拖动调整顺序，插入线提示位置；顺序自动保存。
- 跨卡片默认移动入口，Ctrl 拖动保留源入口；目标已有同项时合并。
- 软件卸载、文件或快捷方式被删除后，自动清理卡片中的失效入口；本地快捷方式的目标被删除也会清理。网络与移动硬盘暂时不可用时保留入口。仅移除引用，不删除原文件。
- 拖回桌面恢复原项；普通外部文件夹默认复制，支持的目标可用 Ctrl+Shift 创建快捷方式。

卡片位于普通应用下方。毛玻璃交给系统合成，不持续截屏或进行 CPU 模糊；系统不支持时使用半透明着色。

## 安装程序

v0.9.0 起提供 `MintDesk-v版本号-setup-x64.exe`，安装到当前 Windows 用户，无需管理员权限。默认目录为 `%LOCALAPPDATA%\Programs\MintDesk`，也可选择其他有写入权限的目录。

| 选项 | 首次安装默认值 |
| --- | --- |
| 创建桌面快捷方式 | 勾选 |
| 登录 Windows 时自动启动 | 勾选 |
| 自动检查更新 | 不勾选；目前只保存参数，不联网、不下载、不提示 |

旧版便携用户直接运行安装包即可：沿用现有 AppData 数据，更新自有快捷方式及已启用的入口，不复制或迁移恢复日志。检测到旧版设置时，按已有桌面快捷方式和自启动状态预选，并保留手动关闭的桌面右键。再次安装会读取已保存的选项及当前自启动状态，也可在安装界面重新选择。

安装和卸载先请求旧版正常退出，等待恢复守护和权限辅助结束，再检查恢复结果。恢复失败或程序仍被占用时停止操作，不强制结束进程。请完成桌面恢复后重试。

安装版更新使用新安装包，继续选择原安装目录。为了避免遗留两个卸载入口，已安装版本需要先卸载再更换目录；卸载保留布局与恢复记录。

**安装完成后可以删除下载的 setup 安装程序。** 安装目录中已有独立的 `MintDesk.exe`，桌面快捷方式和开机启动会指向它，程序本体不能删除。旧便携 EXE 在确认安装完成且不再运行后可自行删除，安装程序不会替你删除旧位置的文件。

## 可选集成

从未配置过的便携版首次正常打开 EXE 会自动配置开机启动和桌面右键，以后登录 Windows 自动恢复上次整理。安装版遵循安装界面的选择，不会在下次运行时重新启用取消的选项。托盘可关闭自启动和桌面右键，后续启动保留选择。右键入口运行时显示“退出薄荷桌面助手”，停止时显示“打开薄荷桌面助手”。Windows 11 通常需要“显示更多选项”。系统启动项策略可能阻止自动启动。

首次配置状态记录在当前用户注册表 `HKCU\Software\MCC\MintDesk`；预览、恢复命令和测试不会自动注册这两项。

便携版默认创建“薄荷桌面助手”桌面快捷方式；安装版可以取消。后续打开不会重复创建，便携版 EXE 位置改变时会刷新目标。同名文件属于其他程序或用户时保留它，改用 `MintDesk` 名称。预览和恢复命令不创建快捷方式。

安装选项保存在同一注册表键中：`DesktopShortcutEnabled`、`AutoCheckUpdates` 为 DWORD 0/1。`AutoCheckUpdates` 目前没有执行逻辑，选中也不会产生网络活动；后续版本可读取这一偏好。

## 更新、移动与快捷方式

以下手动替换与移动流程适用于便携版；安装版推荐运行安装包升级。**桌面快捷方式只是指向 EXE 的入口，必须保留它指向的 `MintDesk.exe`。** 删除程序本体后，快捷方式、自启动和右键入口将无法运行软件。

推荐把程序保存在固定文件夹。更新时先通过托盘或桌面右键正常退出旧版，等待桌面项恢复，再用新版 `MintDesk.exe` 覆盖原位置的旧文件并打开。用户 AppData 中的布局、条目顺序和恢复记录继续沿用。

需要换目录时，同样先正常退出，再移动 EXE，并从新位置打开一次。v0.8.2 起会更新自有快捷方式，以及仍处于启用状态的自启动和右键路径；手动关闭的入口不会重新开启。移动完成前不要删除正在使用的旧文件，不能只把快捷方式当成程序发给别人。

旧版仍在运行时，直接双击另一个目录的新版只会显示现有实例，不会自动替换或切换程序。EXE 的创建和移动权限由 Windows 控制；无法覆盖正在使用的文件时应确认主进程、恢复守护和权限辅助均已正常退出。

公共桌面项可能需要权限。批准 Windows 管理员确认后，受限辅助进程在本次运行内处理相关属性；不安装服务，不修改桌面 ACL。取消授权保留原文件，可从托盘“授权桌面文件操作…”重试。

## 原文件的可见性

桌面直接子项留在原路径，只临时增加 Hidden/System 标记。这会同时影响资源管理器显示；程序不修改文件夹内容或全局显示设置。移除最后一个入口、拖回桌面或正常退出时恢复原属性。重要数据仍应有独立备份。

正常退出必须先完成恢复，失败时保留实例，在卡片内提示重试。使用托盘或桌面右键“退出”；Alt+F4 不关闭卡片。

主程序异常退出时，无窗口守护和已授权辅助进程尝试恢复。断电、所有相关进程同时被结束或日志损坏时可能需要下次启动恢复；原文件仍留在原路径。不要在运行中删除恢复记录。

## 只恢复桌面

先停止正常实例，在 EXE 所在目录运行：

```powershell
.\MintDesk.exe /restore-desktop
```

成功返回 0；已有实例或预览模式返回 1；未全部完成恢复返回 2。受保护项目可能申请管理员确认。旧版本托管文件也通过该流程归还；同名冲突不覆盖已有文件。

## 配置与卸载

新安装的记录保存在 `%LOCALAPPDATA%\MintDesk`。检测到旧版 `%LOCALAPPDATA%\DeskCards` 目录时，会继续原位使用它，避免移动或复制恢复日志及旧托管数据：

**这些记录属于 Windows 用户，与 EXE 所在目录及软件版本无关。** 更新时正常退出旧版、替换 EXE，再打开新版即可沿用卡片、文件入口、顺序和布局，无需重新拖入。无需复制或删除 AppData 中的记录；自定义的边缘间距也会保留。

| 文件 | 用途 |
| --- | --- |
| `state.dat` / `state.backup.dat` | 布局和顺序 |
| `hidden-items.dat` / `hidden-items.backup.dat` | 原可见性与文件身份 |
| `desktop-items.dat` / `desktop-items.backup.dat` | 旧版托管恢复 |
| `Managed/` | 仅旧版可能遗留托管文件 |

安装版可在 Windows“已安装的应用”中卸载。卸载程序先正常退出并完成恢复，再移除属于该安装位置的启动入口、桌面快捷方式和程序文件；保留 AppData 的布局与恢复记录，不递归清理桌面或配置目录。

便携版卸载前关闭自启动、注销桌面右键，正常退出并确认原可见性已恢复。旧版 `Managed` 若仍有文件，先完成归还，再删除 EXE 或配置目录。重置布局也应先完成恢复。

## 命令行

`/show`、`/exit`、`/toggle`、`/new-card`、`/register-menu`、`/unregister-menu`、`/restore-desktop`。

`/preview` 不读写正式布局，禁用桌面托管、菜单注册和恢复命令，不作为日常整理模式。

安装程序内部使用 `/prepare-install`、`/configure-install <桌面快捷方式0/1> <自启动0/1> <更新检查0/1> <桌面右键0/1>` 和 `/uninstall-integrations`，分别用于正常退出并恢复、保存集成选项、清理属于当前 EXE 的入口。
